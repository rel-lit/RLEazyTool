进制转换

使用说明

  • 数值：输入待转换的数，支持整数、小数、负数。二进制只能含 0/1，十六进制含 0-9/a-f/A-F。
  • 源进制 / 目标进制：选择 2、10 或 16。二 ↔ 十六会展示 4 位分组补零过程。
  • 小数精度：仅在 10 → 2/16 且输入含小数时生效，表示保留的小数位数。
  • 示例：13.625（10→2）= 1101.101；1101.101（2→10）= 13.625；6B.A（16→2）= 01101011.1010。

机器码表示

使用说明

  • 真值：输入十进制真值，如 -13、0.625、-0.625。含小数点会自动按纯小数处理。
  • 位宽：总位数（含符号位）。8 位单符号位整数范围 [-128, 127]；纯小数范围 (-1, 1)。
  • 双符号位：使用变形补码（2 位符号 + n-2 位数值），便于判断溢出。
  • 输出包含原码、反码、补码、移码四步可视化。

定点补码加减法

使用说明

  • x、y：输入十进制操作数，支持整数和纯小数。减法会自动转换为 x + (-y)。
  • 位宽：总位数。若结果超出表示范围，会提示溢出。
  • 双符号位：使用变形补码判断溢出，溢出时结果符号位为 01（正溢）或 10（负溢）。
  • 结果会展示 [x]补、[y]补、[-y]补、运算结果、溢出判断及真值。

浮点数加减法

使用说明

  • 尾数：带符号的二进制规格化小数，格式为 +0.xxxxx 或 -0.xxxxx。
  • 阶码：带符号的整数或二进制串，如 +3、-2、+0011。
  • 阶码位宽：阶码总位数，采用双符号位补码（变形补码）。
  • 尾数位数：尾数总位数（含 1 位符号位），采用单符号位补码。
  • 计算流程：对阶 → 尾数加减 → 规格化 → 舍入 → 判溢出。
  • 默认示例即 PDF 例 2.28：x=+0.110101×2³，y=-0.111010×2²，相加结果为 +0.110000×2²。

IEEE 754 浮点转换

使用说明

  • 十进制 → IEEE 754：输入十进制数（支持整数、小数、负数），输出符号位、阶码、尾数及十六进制表示。
  • IEEE 754 二进制 → 十进制：输入完整二进制串（32 位或 64 位），输出真值。
  • 单精度 float32：1 位符号 + 8 位阶码 + 23 位尾数，偏置值 127。
  • 双精度 float64：1 位符号 + 11 位阶码 + 52 位尾数，偏置值 1023。
  • 示例：13.625（float32）= 0x41540000 = 0 10000010 10110000000000000000000。
